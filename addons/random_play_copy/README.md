# RandomPlayCopy

把已经调好的角色材质用到现成动画上。选择着色好的 Blender 工程和对应的 ABC 动作文件，插件会做好新的动画工程，保留描边、刘海透眼和风格面板。动作和物理沿用 ABC，也可以单独导入配套相机。

## 输入与输出

需要准备保存好的角色 `.blend`、对应的 `.abc` 动作文件，以及同目录的 `metadata.json`、`verification.npz`、`material_animation.npz`。角色工程可以由 [RandomPlayToon](../random_play_toon/README.md) 制作；三个检查文件由动画导出流程一并生成。相机 `.vmd` 可选。

会得到一个新的动画 `.blend` 和套用报告。材质、纹理、描边、透眼和光照控制都会保存，相机导入后也保存在工程中。**播放和渲染仍需要外部 ABC**，移动工程时一起保留它。

当前支持普通版薇薇安和千夏女仆的匹配动画。模型必须与着色模板一致，不能改变顶点顺序、纹理位置或材质分区。只有普通 ABC 而没有配套检查文件时，暂时不能直接套用；材质、可见性或 UV 随时间变化的动画还需要额外处理。准备方式见 [工作流程](../../docs/WORKFLOW.md)。

## 面板与操作

![RandomPlayCopy 操作面板](../../docs/images/copy-panel.png)

在 Blender 5.2 安装并启用本插件后，3D 视图按 N，打开 **ABC渲染**。

| 控件 | 作用 |
| --- | --- |
| 已着色模板 | 选择保存好的静态 `.blend`；未保存的参数调整不会进入后台任务 |
| 动画缓存 | 选择符合验证结构的 `.abc` |
| 输出完整路径／选择目录 | 指定新 `.blend` 的完整保存位置，可先选目录再改文件名 |
| 输出帧率 | 跟随 ABC 或选 30／60 fps；改变帧数，保持动作秒数不变 |
| ABC 已含预热（秒） | 记录缓存已有的预热，供相机初始偏移使用 |
| 将渲染效果套用到 ABC | 后台校验并生成动画工程 |
| 打开结果 | 打开生成的工程，任务完成后显示 |

打开结果后播放时间轴，在 **ABC渲染 → 角色风格** 调整效果并保存。按 F12 查看最终描边、透眼和辉光。Copy 自带风格面板，两个插件也可以同时安装。

## 可选相机

展开 **可选相机 VMD · 帧率与预热对齐**，选择相机文件、填写源帧率和缓存已有的预热秒数，点击 **导入相机并按目标帧率采样**。

源相机 30 fps、场景 60 fps 时，额外时长倍数保持 **1**：帧号翻倍而秒数不变。预热设为 1 秒时，相机在 60 fps 下延后 60 帧；它不会向角色缓存补加静止段。空间比例默认跟随 ABC。

修改预热或时长后，用 **按上述设置重新对齐相机** 从工程保存的源相机轨道重新采样；此操作替换本工具相机的手动调整。修改场景帧率后，用 **同步 ABC 时间轴到当前帧率** 对齐本工具管理的头部控制、时间轴与相机。更多按钮和参数见 [面板与参数说明](../../docs/CONTROLS.md)。

角色模型、纹理、渲染素材和动画缓存不包含在仓库或安装包中。安装包制作见 [工作流程](../../docs/WORKFLOW.md)，许可见 [LICENSE](LICENSE) 与 [NOTICE](NOTICE)。
