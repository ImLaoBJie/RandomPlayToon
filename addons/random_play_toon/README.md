# RandomPlayToon

选择已适配的绝区零角色模型、纹理和渲染素材，点击“一键重建”，得到能在 Blender EEVEE 中直接渲染的角色工程。材质、灯光、描边和刘海透眼会自动做好，之后可以自由调风格。

PMX 导入功能已包含在安装包中，**不需要另外安装 MMD Tools**。

## 输入与输出

输入是一个 `.pmx`、模型包自带纹理，以及对应角色／服装的 DDS 渲染素材目录。模型从 [模之屋](https://www.aplaybox.com/) 原发布页获取；素材从 [ZZ-Model-Importer-Assets](https://github.com/leotorrez/ZZ-Model-Importer-Assets/tree/main) 获取。保留原目录和索引，具体结构见 [输入准备](../../docs/WORKFLOW.md)。仓库与安装包不包含 PMX、游戏原始纹理或渲染素材。

输出是新的 `.blend`，保存用户提供的模型与纹理、骨骼和网格表情、材质、灯光、效果合成和参数面板，另有构建报告。可用于角色展示、图片渲染、继续制作动作，或作为 [RandomPlayCopy](../random_play_copy/README.md) 的着色模板。

## 面板与操作

![RandomPlayToon 操作面板](../../docs/images/toon-panel.png)

在 Blender 5.2 中安装并启用本插件后，3D 视图按 N，打开 **RandomPlayToon**。

| 控件 | 作用 |
| --- | --- |
| 选择模型 PMX／模型 PMX | 选择角色的 `.pmx` 文件，插件会检查它是否属于已适配的版本 |
| 配套纹理目录 | 原纹理的根目录；与 PMX 一起解压时通常可留空 |
| 渲染素材目录 | 对应角色 DDS 与索引所在目录，可选角色目录或素材库根目录 |
| 输出新文件 | 指定新的 `.blend` 路径 |
| 保留当前个人参数 | 重新构建角色时，沿用已经调好的风格 |
| 完成后自动打开 | 当前是空白工程且未发生改动时自动打开结果 |
| 一键重建 | 在独立后台 Blender 中构建新工程 |
| 打开重建结果 | 打开生成的工程，任务完成后显示 |
| 查看例外与构建报告 | 查看识别、匹配、处理例外和输出信息 |

打开结果后，在以角色英文名命名的 N 侧栏中调节风格，保存模板并用 **F12** 查看最终透眼和辉光。已有结果可直接打开调参；不必重新导入 PMX。参数含义见 [面板与参数](../../docs/CONTROLS.md)，安装包制作见 [工作流程](../../docs/WORKFLOW.md)。

## 效果与范围

模型原纹理提供颜色和透明信息，渲染素材提供阴影、高光、法线等信息。插件按角色设置把它们接到材质上。脸、皮肤、头发、衣服和金属饰件可以分别调整，脸部受光会跟随头部方向。刘海透眼让眼睛在指定前刘海后显现，其他部位仍正常遮挡。通常不需要把各个部位拆成独立物体。

支持已经适配的角色、服装、形态和独立武器。插件会检查文件内容；不同改模、新版模型或不同贴图需要另做适配。PMX 材质变形制作的动态效果也需额外处理。角色示例和适用范围见 [项目首页](../../README.md)。

源码中，`pmx_import.py` 负责内置 PMX 导入，`core.py` 串起构建流程，`materials/` 制作材质，`effects/` 处理描边、透眼和后期，`specializations/` 保存角色设置和必要校准数据。内置 MMD Tools 导入代码与参考 shader 的来源、许可见 [NOTICE](NOTICE) 和 [LICENSE](LICENSE)。
