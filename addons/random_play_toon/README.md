# RandomPlayToon

AliceSummer、LucySummer、VivianSummer、YuzuhaSummer 新建时默认使用 `01_CrispCel` 参数与真实场景灯光。预设按登记的 PMX 版本和材质分区匹配；个人参数优先，打开已有工程不会自动套用。

四套 `02_CoolGlow` 参数可通过风格面板已有的 **载入个人预设** 按钮导入：使用独立虚拟光照与亮块。**场景响应／独立展示光照切换只改变光照方式，不会载入另一套完整参数。** JSON 导入恢复面板参数，灯光对象、世界和相机保留当前工程设置；要使用既有完整场景，直接打开对应的 `02_CoolGlow` 工程。

四个泳装角色的渲染素材目录可留空，仍可构建并载入默认参数；配套头发／帽子高光及依赖控制图的饰件细节需要对应的、校验通过的渲染素材。安装包不捆绑角色 PMX、原贴图或 DDS 素材。

共 **17 个角色／形态配置**，不计独立武器、附件和特效；[角色列表见项目首页](../../README.md#适合用在哪些地方)。其他 PMX 仍可使用原贴图通用构建，渲染素材目录可留空。

| 范围 | 角色与变体 |
| --- | --- |
| 既有校准配置（13） | Vivian（薇薇安）、Alice（爱丽丝）、SunnaMaid（千夏皮肤）、Yuzuha（柚叶）、Pyrois（佩洛伊斯）、AriaDiscordant（爱芮）、AriaRobotDiscordant（爱芮机器人）、NangongYuRapsody（南宫羽）、Yidhari（伊德海莉）、YeShunguang（叶瞬光）、YeShunguang_White（叶瞬光白色变体）、Norma（诺姆）、Remielle（蕾米埃尔） |
| 泳装默认预设（4） | AliceSummer、LucySummer、VivianSummer、YuzuhaSummer |

选择已适配的绝区零角色模型、纹理和渲染素材，点击“一键重建”，得到能在 Blender EEVEE 中直接渲染的角色工程。材质、灯光、描边和刘海透眼会自动做好，之后可以自由调风格。

PMX 导入功能已包含在安装包中，**不需要另外安装 MMD Tools**。

## 输入与输出

输入是一个 `.pmx`、模型包自带纹理，以及对应角色／服装的 DDS 渲染素材目录。模型从 [模之屋](https://www.aplaybox.com/) 原发布页获取；素材从 [ZZ-Model-Importer-Assets](https://github.com/leotorrez/ZZ-Model-Importer-Assets/tree/main) 获取。保留原目录和索引，具体结构见 [输入准备](../../docs/WORKFLOW.md)。仓库与安装包不包含 PMX、游戏原始纹理或渲染素材。

输出是新的 `.blend`，保存用户提供的模型与纹理、骨骼和网格表情、材质、灯光、效果合成和参数面板，另有构建报告。可用于角色展示、图片渲染、继续制作动作，或作为 [RandomPlayCopy](../random_play_copy/README.md) 的着色模板。

## 面板与操作

![RandomPlayToon 操作面板](../../docs/images/toon-panel.png)

在 Blender 5.2 中安装并启用本插件后，3D 视图按 N，打开 **RandomPlayToon**。

| 控件 | 作用 |
| --- | --- |
| 选择模型 PMX／模型 PMX | 选择角色的 `.pmx` 文件；已适配版本走校准流程，其余使用通用材质 |
| 配套纹理目录 | 原纹理的根目录；与 PMX 一起解压时通常可留空 |
| 渲染素材目录 | 对应角色 DDS 与索引所在目录，可选角色目录或素材库根目录 |
| 输出新文件 | 指定新的 `.blend` 路径 |
| 保留当前个人参数 | 重新构建角色时，沿用已经调好的风格 |
| 完成后自动打开 | 当前是空白工程且未发生改动时自动打开结果 |
| 一键重建 | 在独立后台 Blender 中构建新工程 |
| 打开重建结果 | 打开生成的工程，任务完成后显示 |
| 查看例外与构建报告 | 查看识别、匹配、处理例外和输出信息 |

打开结果后，先把任意窗口切换为 **文本编辑器**，在顶部的文本列表中选择 **`01_启用风格面板`**，点击 **运行脚本**，或把鼠标放在文本编辑器内按 **Alt+P**。运行一次后，回到 3D 视图按 **N**，在角色英文名对应的侧栏中调节风格。重新启动 Blender 后，如果面板没有出现，再运行一次。

保存模板并用 **F12** 查看最终透眼和辉光。已有结果可以直接打开调参；不必重新导入 PMX。参数含义见 [面板与参数](../../docs/CONTROLS.md)，安装包制作见 [工作流程](../../docs/WORKFLOW.md)。

## 效果与范围

模型原纹理提供颜色和透明信息，渲染素材提供阴影、高光、法线等信息。插件按角色设置把它们接到材质上。脸、皮肤、头发、衣服和金属饰件可以分别调整，脸部受光会跟随头部方向。刘海透眼让眼睛在指定前刘海后显现，其他部位仍正常遮挡。通常不需要把各个部位拆成独立物体。

支持已适配的角色、服装、形态和独立武器，也允许未校准 PMX 使用通用材质。通用构建的部位识别依赖材质名称，不包含专用控制图校准；需要更精细的还原时再做适配。PMX 材质变形制作的动态效果也需额外处理。角色示例和适用范围见 [项目首页](../../README.md)。

源码中，`pmx_import.py` 负责内置 PMX 导入，`core.py` 串起构建流程，`materials/` 制作材质，`effects/` 处理描边、透眼和后期，`specializations/` 保存角色设置和必要校准数据。内置 MMD Tools 导入代码与参考 shader 的来源、许可见 [NOTICE](NOTICE) 和 [LICENSE](LICENSE)。
